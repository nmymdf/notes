# DeskNotes — Windows 桌面筆記（＋安卓手機版）

一個類似 Samsung Notes 的 Windows 桌面筆記 App，不需要帳號、資料全部存在自己電腦。

## 功能

- **隨時記事**：關閉視窗會縮到系統匣，任何時候按 **Ctrl + Alt + N** 就會跳出並開一則新筆記
- **貼圖**：在編輯器 **Ctrl + V** 直接貼上截圖（Win + Shift + S 截完直接貼）、拖曳圖片進來、或按工具列的圖片按鈕
  - 在筆記列表畫面直接 Ctrl + V，會自動用剪貼簿內容（圖片或文字）建立新筆記
  - 點圖片可畫圖或刪除；雙擊圖片或在圖片上按 Ctrl + 滑鼠滾輪放大檢視，滾輪縮放、拖曳移動，Esc 關閉
- **畫圖（電腦版）**：工具列的 ✏️ 按鈕開一張白紙手繪，完成後變成筆記裡的圖片
  - 工具：筆、螢光筆、直線、箭頭（按住 Shift 畫水平／垂直）、方框、圓圈、文字、橡皮擦（點一下擦掉整筆）；6 種顏色、細／中／粗；Ctrl + Z / Ctrl + Y 復原／重做
  - 背景可選白色、黑色、方格紙
  - **在圖片上畫**：點筆記裡的圖片 →「✏️ 畫圖」，可圈重點、加箭頭或文字。原圖會保留，隨時可按「還原原圖」
  - 畫好的圖之後還能繼續修改（雙擊圖片或按「✏️ 畫圖」），每一筆都還在
  - 資料夾裡的圖片檔：右鍵「畫圖（另存新檔）」，會存成「原檔名（標註）.png」，原檔不變
  - 上鎖筆記裡畫的圖一樣加密
  - 手機也能用手指畫：工具列的 ✏️ 開白紙；點圖片放大後按「✏️ 畫圖」在圖上畫。兩邊畫的圖同步後都能繼續修改
- **網址連結**：筆記裡的網址（打字或貼上）會自動變成藍色連結，點一下就用瀏覽器打開（電腦、手機都可以）
- **左側欄**：右邊邊線可以用滑鼠左右拖曳調整寬度；「垃圾筒」上面的分隔線可以上下拖曳調整資料夾區高度；雙擊回到預設，會記住。左下角只有「垃圾筒」和「⚙ 系統」，其他功能（手機同步、外觀、備份、匯入）都在「系統」裡
- **外觀**：左側選單下面「外觀：黑底／白底」可以切換，每台電腦、手機各自記住（預設黑底）
- **語音輸入**：編輯器工具列的「語音輸入」按鈕、列表的「語音筆記」，或 **Ctrl + Shift + M**（使用 Windows 內建語音輸入 Win+H，需在 Windows 設定安裝「中文（台灣）」語言）
- **上鎖筆記**：左側「上鎖筆記」用密碼保護重要資料（AES-256 加密，文字與圖片都加密）
  - 一般筆記可按右鍵「移到上鎖筆記」、多選後按「上鎖」，或直接拖曳到左側「上鎖筆記」
  - 輸入一次密碼後會保持開啟，直到按「立即上鎖」或完全結束 DeskNotes（系統匣右鍵 →「結束」）
  - ⚠ 程式不保存密碼，**忘記密碼就無法找回內容**
- **匯入 Outlook 記事**：左下角「匯入 Outlook 記事…」，每則 Outlook 記事變成一則筆記，放在「Outlook 記事」資料夾
  - Outlook 2010 匯出方式：檔案 → 開啟 → 匯入/匯出 → 匯出至檔案 → 逗點分隔值 (Windows) → 選「記事」資料夾
  - 標題與內容在同一欄（記事本文）時，自動取開頭到第一個空格／換行／冒號當標題（最多 30 字）
  - 匯入前會先預覽，可自行選擇欄位；自動判斷 Big5／UTF-8／UTF-16 編碼；已匯入過的會略過
  - 匯入後左下角有「刪除上次匯入的 N 則」，可一鍵復原
- **編輯**：標題、粗體、斜體、底線、刪除線、文字顏色、螢光筆、項目符號、編號、待辦清單（可打勾）、縮排、分隔線
- **整理**：所有筆記 / 未分類 / 我的最愛 / 資料夾 / 垃圾筒（保留 30 天，可還原）
  - 資料夾最多兩層：把資料夾拖到另一個資料夾上面就變成子資料夾，拖到兩個資料夾中間可調整順序
  - 資料夾右鍵：新增子資料夾、重新命名、合併到其他資料夾、設為新筆記預設資料夾、移到上鎖筆記、刪除
  - 上鎖筆記裡也可以建資料夾（名稱一起加密）；把資料夾拖到「上鎖筆記」會整個加密保存
- **顏色標記**：紅／黃／綠三色（＋無色），右鍵、編輯畫面上方或多選後設定；列表上方可依顏色篩選
- **瀏覽**：卡片 / 清單 / 標題＋內容兩欄 三種檢視、依修改日期 / 建立日期 / 標題排序、全文搜尋
- **其他**：多選批次移動或刪除、視窗置頂、匯出成 HTML（圖片內嵌）、開機自動啟動（系統匣右鍵）

## 快捷鍵

| 按鍵 | 功能 |
|---|---|
| Ctrl + Alt + N | 在任何地方叫出 App 並新增筆記 |
| Ctrl + N | 新增筆記 |
| Ctrl + Shift + M | 語音輸入（在列表時會先建立新筆記） |
| Ctrl + F | 搜尋 |
| Ctrl + V | 貼上圖片／文字 |
| Ctrl + 點卡片 | 多選 |
| Shift + 點卡片 | 一次選取一整段 |
| Esc | 返回列表 |

## 安卓手機版

下載：<https://github.com/nmymdf/notes/releases/latest/download/DeskNotes.apk>

- 用手機瀏覽器打開上面的連結下載，點下載好的檔案安裝；第一次會要求允許「安裝不明來源的應用程式」
- 功能和電腦版相同：資料夾、上鎖筆記、顏色、搜尋、檢視模式、插入圖片
- 左上角 ☰ 打開選單；手機的返回鍵可關閉視窗、返回列表
- 圖片放大：點一下圖片，或兩指直接在圖片上拉開，就會全螢幕放大。兩指縮放、一指拖動，點兩下切換放大／整張，🗑 刪除圖片，✕ 或返回鍵關閉（資料夾裡的圖片檔預覽也一樣）
- 語音輸入：用手機鍵盤上的麥克風
- 目前**不會和電腦同步**，手機和電腦的筆記是分開的
- 更新：下載新的 DeskNotes.apk 直接安裝即可，筆記會保留（不要先解除安裝，解除安裝會刪除手機上的筆記）

## 資料夾裡的檔案（傳檔用）

每個資料夾都可以同時放筆記和檔案（mp3、mp4、pdf、txt…）：在資料夾裡按「建立筆記」或「加入檔案」，列表上面是筆記、下面是檔案。最多兩層，可拖曳排序。上鎖筆記只能放筆記，有檔案的資料夾不能移到上鎖筆記。

- **電腦**：每個資料夾都是真的資料夾（只放檔案，筆記不在裡面），原本的檔名，位置在 `%APPDATA%\DeskNotes\data\files\`
  - 資料夾右鍵「在檔案總管中開啟」；也可以直接在檔案總管把檔案放進去／刪掉，DeskNotes 會自動發現
  - 點檔案用預設程式開啟；可以直接把檔案從檔案總管拖進 DeskNotes
  - 把筆記或檔案拖到桌面（或檔案總管的資料夾）就會複製一份過去；筆記會存成 .html（含圖片）。也可以右鍵「複製到桌面…」
- **手機**：「複製到手機」存好後可以按「打開資料夾」，用手機的檔案 App 打開 文件/DeskNotes 自己整理
- **手機**：圖片、音樂、影片、文字檔在 DeskNotes 裡直接開啟；其他檔案（pdf、Word…）點一下會「分享」，選擇用哪個 App 開啟或傳給誰
- 同步時檔案會一起互傳（只傳有變動的，大檔案分段傳送）
- 刪除的檔案先進垃圾筒，30 天內可還原；單一檔案上限 200 MB；檔案不加密、不能放進上鎖筆記

## 手機 ⇄ 電腦同步（家裡 Wi-Fi，手動）

手機和電腦連同一個 Wi-Fi 時，在手機按「與電腦同步」，兩邊的筆記、圖片、資料夾、上鎖筆記會合併成一樣。資料只在家裡網路內傳送，而且全程加密。

**第一次配對**
1. 電腦：左下角「📱 手機同步…」→ 勾選「允許手機同步」→「＋ 配對新手機」
   - Windows 若跳出防火牆詢問，請按「允許存取」（勾選「私人網路」）
2. 手機：選單 ☰ →「與電腦同步」→ 輸入電腦上顯示的「電腦位址」和 6 位數「配對碼」

**之後**：手機按「與電腦同步」即可（電腦的 DeskNotes 要開著，縮在系統匣也可以）。

**合併規則**
- 兩邊相同的不重複傳送；只傳有變動的部分
- 內容不同時，新的蓋舊的；兩邊都改過同一則時，舊版會放到垃圾筒（30 天內可還原）
- 刪除也會同步（移到垃圾筒、清空垃圾筒都會）
- 上鎖筆記：兩邊要用**同一組密碼**，而且手機要先解鎖才會同步上鎖筆記（電腦不用解鎖）

## 自己編譯

需要先安裝 [Node.js](https://nodejs.org/)（LTS 版）。

```bash
npm install
npm start          # 直接執行
npm run dist       # 產生 Windows 安裝檔到 dist/
npm run android    # 產生安卓專案的網頁資源並同步到 android/（需 Android SDK 才能建置 APK）
```

## 備份（電腦）

- **自動備份筆記**：每天第一次打開 DeskNotes，以及每次和手機同步之前，都會自動備份一次筆記、圖片和上鎖筆記，保留 30 天
  - 上鎖筆記在備份裡一樣是加密的，沒有密碼看不到
  - 位置：`%APPDATA%\DeskNotes\data\backups\`
- **從備份找回筆記…**（左側選單下方）：選一個日期，把那時候有、現在卻不見的筆記加回來；現有的筆記不會被改變。要找回上鎖筆記，請先解鎖
- **設定備份位置…**：設定一次「備份全部」要存到哪裡（例如隨身碟），之後按「備份全部」就直接存過去；位置找不到時（隨身碟沒插）會提醒
- **備份全部…**：把全部複製到你選的位置（例如隨身碟）：「筆記」每則一個 .html（用瀏覽器就能看，含圖片）、「檔案」資料夾裡的所有檔案、「還原用資料」（含加密的上鎖筆記）。檔案可能很大，所以只有按這個才會備份檔案
- 「從備份找回筆記…」也可以選「從其他位置選擇備份」，從隨身碟上的備份找回

## 資料存放位置

`%APPDATA%\DeskNotes\data\`

- `notes.json`：所有筆記與資料夾（每次存檔會留一份 `notes.json.bak`）
- `images\`：貼上的圖片
- `vault.enc`、`vault-images\`：上鎖筆記（已加密，沒有密碼無法讀取）

備份只要複製整個 `data` 資料夾即可。系統匣右鍵選單有「開啟資料夾位置」。
